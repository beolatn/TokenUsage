# Contributing to Token Usage

Thanks for taking the time to contribute. All input is welcome — bug reports, feature ideas, and pull requests.

## Reporting a Bug

Open an issue on GitHub and include:

- What you expected to happen
- What actually happened
- Your Obsidian version and operating system
- Whether the problem is reproducible (and if so, how)

The more specific, the faster it gets fixed.

## Suggesting a Feature

Open an issue with a short description of what you want and why it would be useful. No template required — a plain explanation is fine.

## Submitting a Pull Request

1. Fork the repository
2. Create a branch: `git checkout -b feature/your-feature-name` or `fix/your-fix-name`
3. Make your changes
4. Test with a local Obsidian vault (copy `main.js`, `styles.css`, `manifest.json` into `.obsidian/plugins/token-usage/` and reload)
5. Open a pull request with a short description of what changed and why

## Notes

- This plugin has no build step — `main.js` is vanilla JavaScript, edited directly
- All UI text, comments, and documentation are in English
- Please keep pull requests focused: one fix or feature per PR makes review faster

## Translations

Translations into other languages are planned. If you are a native speaker of French, Italian, or Spanish and would like to contribute, watch this repository — a dedicated issue will be opened when the translation infrastructure is ready.

## Questions

If you are unsure whether something is worth an issue or a PR, just open an issue and ask. No question is too small.
